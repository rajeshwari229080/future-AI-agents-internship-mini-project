🚀 **Excited to share my latest project: Student Record Management System!**

Just completed building a **full-stack, production-grade Student Record Management System** as part of my internship at **EWB Edu Tech Pvt. Ltd.** 🎓

---

**What I built:**

🏗️ **Backend Architecture**
→ FastAPI (Python 3.11) with async endpoints
→ SQLAlchemy 2.0 ORM with SQLite persistence
→ Pydantic v2 strict validation with custom business rules

📋 **Complete CRUD Operations**
→ Create students with full profile fields
→ Read with pagination, case-insensitive search & course filtering
→ Full replacement (PUT) and partial updates (PATCH)
→ Safe deletion with 404 handling

🎨 **Professional Admin Dashboard**
→ Responsive single-page interface (HTML + CSS + JS)
→ Live statistics cards & course distribution overview
→ Modals for Add / Edit / View Profile / Delete confirmation
→ Toast notifications & inline validation feedback

🤖 **Optional Local AI Assistant (Ollama)**
→ Natural-language queries grounded in database context
→ Privacy-first: no contact details sent to the model
→ Graceful offline fallback with exact database metrics
→ 100% deterministic counts — zero hallucinations

🧪 **25 Automated Tests (pytest)**
→ All passing — CRUD, validation, pagination, persistence, AI mocks
→ Isolated test database fixtures for clean test environments

🔒 **Security Controls**
→ ORM-only parameterized queries (no raw SQL)
→ XSS-safe frontend (textContent APIs)
→ Security headers, no secrets in version control

---

**Tech Stack:**
`Python` · `FastAPI` · `SQLAlchemy` · `SQLite` · `Pydantic v2` · `Jinja2` · `Uvicorn` · `Pytest` · `Ollama (llama3.2:1b)`
